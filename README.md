# 📋 Todo App — список задач

Веб-приложение для управления списком задач. Запускается через **Docker Compose** и использует **Flask** + **PostgreSQL**.

## 🚀 Быстрый старт

```bash
git clone https://github.com/ecstase-art/todo-app.git
cd todo-app
docker-compose up --build
